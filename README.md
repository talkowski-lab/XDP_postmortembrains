# XDP_postmortembrains
Repository for preprocessing and analysis scripts for RNA-Seq data for the paper, "X-linked dystonia-parkinsonism is a genetic four-repeat tauopathy"

## RNA extraction, sequencing, and preprocessing						
RNA was extracted from brain pieces following bead-based homogenization using Trizol. Following quantification and quality control for RNA integrity using a Bioanalyzer, polyA-enriched mRNA-Seq libraries were constructed using the Illumina TruSeq Stranded mRNA kit. Libraries were sequenced using an Illumina NovaSeqX, with each library receiving a minimum of 25 million and a maximum of 107 million paired-end 150-bp reads. Raw fastq sequences were obtained and qualities were assessed using FastQC and RNA-SeqQC, adapters were trimmed using trimmomatic v0.36, then alignment to the human genome reference (GRCh38) was performed using STAR v2.7.10 with the following parameters: --outFilterMultimapNmax 1 --outFilterMismatchNoverLmax 0.05 --alignEndsType EndToEnd. Gene counts were obtained directly from STAR. Intron retention in TAF1 intron 32 was measured using IRFinder. [https://github.com/talkowski-lab/XDP_postmortembrains/tree/main/Preprocessing](Link to scripts used for preprocessing).

RNA-Seq differential expression analysis, enrichment analysis, and coexpression Analysis										
Differential expression analysis was performed in R using DESeq2 v1.46.0 for each brain region (striatum: 28 XDP, 10 controls; cerebellum: 37 XDP, 13 controls; prefrontal cortex: 36 XDP, 11 controls; occipital cortex: 34 XDP, 13 controls; all male, Supplementary Table 1). Prior to obtaining DEGs, features were filtered for low expression (only genes with >1 cpm were included), resulting in the following number of genes analyzed per brain region: striatum 13878, cerebellum 13943, prefrontal cortex 13687, and occipital cortex 13495. Normalization was performed using DESeq median-of-ratios method135, then principal component analyses were used to determine the suitability of models that incorporated surrogate variables136 (obtained via the SVAseq v3.54.0 package) to regress out unwanted technical variables from the differential expression analyses. DEGs were obtained at a predetermined false-discovery rate (FDR)-adjusted p-value cutoff of <0.01 and log2(fold-change) cutoff >0.58 (for upregulated genes) or log2(fold-change) <-0.58 (for downregulated genes). AnnotationDB v1.6.8 was used to convert features to gene symbols. All DESeq2 results are found in Supplementary Table 3.	To determine direction-dependent overlaps between DEGs across brain regions, we used genes with adj-p<0.01 (regardless of fold-change) and tested for overlap via hypergeometric tests, using the minimum set of overlapping features detected per brain region as background. Marker genes for striatal MSNs (related to Fig. 4b) were obtained from the literature137. For the analysis of genes that are dysregulated according to (CCCTCT)n repeat length, we first subsetted to genes that were already determined to be DEGs in the striatum. A linear model was then constructed using (CCCTCT)n repeat length (among XDP samples) and normalized expression as variables to determine the DEGs that show greater upregulation/downregulation with increasing (CCCTCT)n repeat length. Cutoff p-value was set to p<0.05. Genes and slope of the linear models are in Supplementary Table 4.		
All functional enrichment analyses of gene lists (DEGs, overlapping DEGs, DEGs dysregulated according to repeat-number, module genes) were performed using the R package for gprofiler2 v0.2.3, using the query sets "GO:BP", "GO:CC", "GO:MF", "KEGG", "REAC", "WP". Background was set to genes analyzed per brain region and p-values were FDR-adjusted. Enrichments with adj-p< 0.05 were manually curated for representation in Fig. 4a, and the full list of enrichments in DEGs is in Supplementary Table 5. Enrichment of DEGs within curated lists obtained from the literature was also performed using Fisher’s exact tests. In particular, to identify overlaps with dysregulated genes in HD MSNs, we used gene statistics from Handsaker et al.77, and parsed the overlap of downregulated DEGs in the striatum (this dataset) and “C- phase” genes (HD dataset).  Gene modules from coexpression networks in AD prefrontal cortex were obtained from Mostafavi et al.86 and overlapped with coexpression modules obtained from XDP prefrontal cortex.												
Cell-type deconvolution analyses were performed using CIBERSORTx138. XDP and control RNA-Seq profiles from the striatum and occipital cortex (as negative control) were uploaded to the CIBERSORTx online platform (last accessed: July 23, 2025), and cell fractions were imputed using the relative run mode and using brain transcriptome signatures from a benchmarking paper for in silico cell type deconvolution139 of bulk RNA-Seq data. Cell-type proportion changes between XDP and control for each region were estimated using independent t-tests.	
Coexpression analyses were performed using the R package WGCNA v1.3 (Weighted Gene Network Coexpression Analysis)140. Normalized count matrices (30 XDP, 6 controls, all from prefrontal cortex, representing RNA-Seq libraries with measurable IR in TAF1 intron 32) were log-transformed and then used to create signed networks from adjacency and topological overlap matrices, at soft power threshold of 20. Minimum gene module size was set to 50 genes, resulting in 24 gene modules. These modules were then refined to include only genes with module membership p<0.05 in their original assigned modules; otherwise, genes were reassigned to the unclassified module (M0), which eventually contained 1689 genes (out of 12059 genes). Module eigengenes were then correlated with traits (ME-trait correlations) and enrichment of DEGs within modules was tested using hypergeometric testing; only modules with ME-trait correlation > 0.30 and enrichment with DEGs adj-p<0.01 were included in Fig. 4f.
Transcriptomic data are deposited in dbGap Project: phs001525.v2.p1. Scripts for preprocessing and analyses are available on github: github.com/talkowski-lab/XDP.Brains.
